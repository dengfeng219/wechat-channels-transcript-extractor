视频号文案提取器

微信视频号视频 → 解密 → 本地语音识别 → 文案稿（全本地处理，音视频不上传）
正在检测环境…
获取方式：微信打开视频 → 右下角「分享」→「复制链接」。
也可以把微信里复制的整段文字直接粘进来，会自动挑出里面的链接、自动去重。
解析需要腾讯元宝登录态（首次要配置一次，见下方「登录态设置」）。
点击选择文件，或把文件拖到这里
支持 mp4 / mov / mkv / m4a / mp3 / wav 等
若视频来自其它下载工具，粘贴其提供的直链与 decode_key 即可自动解密。
免登录拿不到视频文件时用这个
视频号视频在微信里能正常播放，但文件拿不到 —— 那就把电脑正在播放的声音录下来做识别。
① 在微信里打开这条视频并播放（保证有声音）
② 回到这里点「开始录制」
③ 视频播完点「停止并转写」
登录态设置 —— 解析分享链接必填（点这里展开）
推荐方式一：一键获取，不用碰开发者工具
点下面的按钮会弹出一个浏览器窗口 → 用微信扫码登录腾讯元宝 → 本程序自动读取登录态并关闭窗口。
方式二：手动粘贴（已登录的浏览器里复制）
支持直接粘贴 Cookie 串，也支持整段「复制为 cURL」、请求头片段、Cookie 插件导出的 JSON。
最稳的做法：在元宝页面按 F12 → 网络面板 → 筛选框输入 yuanbao → 在请求上右键 → 复制 → 以 cURL 格式复制 → 粘贴到下面。
注意：别选 api.aida.qq.com、google-analytics、 sentry 这类第三方统计请求，它们不带元宝的 Cookie。
文案校对设置 —— 大幅减少错别字（点这里展开）
推荐AI 上下文校对
识别引擎是逐音判断的，像「就算这里了，点个恨通」这种同音字， 只有懂上下文才改得对。填一个大模型 API Key，每次提取完会自动校对一遍。
Key 只存在本机 config.json，只发给你填的这个接口。
自定义替换表（离线生效，不需要 Key）
每行一条，格式 错词=对词。内置了一批短剧常见套话的修正 （如 点个恨通→点个赞吧、留不接→留不住）。遇到反复出现的错字就加到这儿。
